# guide-zh-portal

## 项目简介

guide-zh-portal 是一个用于归档和发布独立 HTML 页面的仓库。  
本仓库不针对任何特定域名或网站，仅作为多个 HTML 页面的集中存放与分发入口。  
页面内容以中文为主，涵盖各类指南、说明与信息展示，供有需要的用户查阅或使用。

## 目录说明

```
guide-zh-portal/
├── pages/          # 存放所有独立 HTML 页面
├── assets/         # 公共资源文件（CSS、JavaScript、图片等）
├── index.html      # 仓库入口页面（可选）
└── README.md       # 本文件
```

- `pages/` 目录下每个子文件夹或文件对应一个独立页面，按主题或用途命名。
- `assets/` 目录存放页面共用的样式、脚本或媒体资源，便于统一管理。
- `index.html` 可作为导航首页，汇总所有页面的链接（若存在）。
